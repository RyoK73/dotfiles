## 壁打ちフェーズ

この計画のあらゆる側面について、共通理解に達するまで容赦なくインタビューを行う。設計ツリーの各分岐を一つずつ辿り、決定間の依存関係を順番に解決していく。

質問は一度に一つずつ行うこと。

コードベースを調べることで答えられる質問がある場合は、インタビューの代わりにコードベースを調べること。

## 実装方法の選択

壁打ちフェーズが完了したら、必ず`AskUserQuestion`で次を確認する。

- 「claudeが実装する（会話内容をドキュメントに保存してからプランモードで進める）」
- 「自分で実装する（会話内容をドキュメントに保存して終了）」

どちらを選んでも、壁打ち内容は必ず保存し、保存先の絶対パスを案内する。

### claude 実装

先に下記の{壁打ち内容の保存}を実行し、保存先を案内する。
その後、プランモードで実行する。
{壁打ちフェーズ}の結果をもとに実装計画を立て、実装する。

### 壁打ち内容の保存（実装方法を問わず必須）

壁打ち内容を、本体リポジトリの `.git` 直下に保存する。
コミット対象や `.gitignore` に影響させない。
worktree で実行しても、全worktreeの壁打ち内容が本体の `.git` に集まる。

```bash
dir="$(git rev-parse --path-format=absolute --git-common-dir)/grill-me"
mkdir -p "$dir"
file="$dir/$(date +%Y-%m-%d)-{テーマのスラッグ}.md"
```

ファイル名: `{YYYY-MM-DD}-{テーマのスラッグ}.md`

フォーマット:

```markdown
---
date: { YYYY-MM-DD }
tags: [grill-me]
repository: { repository-name }
---

# {テーマ}

## 決定事項

{壁打ちフェーズで確定した内容を箇条書きで}

## 実装方針

{決定を踏まえた実装アプローチ}
```

保存後、ファイルの絶対パスをテキストで表示する（`file://` は付けない）。

## 終了（ユーザーが実装する場合）

コードは一切書かない。保存したドキュメントのパスを再度案内してセッションを終了する。
