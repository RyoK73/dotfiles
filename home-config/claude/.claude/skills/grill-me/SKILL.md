## 壁打ちフェーズ

この計画のあらゆる側面について、共通理解に達するまで容赦なくインタビューを行う。設計ツリーの各分岐を一つずつ辿り、決定間の依存関係を順番に解決していく。

質問は一度に一つずつ行うこと。

コードベースを調べることで答えられる質問がある場合は、インタビューの代わりにコードベースを調べること。

## 実装方法の選択

壁打ちフェーズが完了したら、必ず`AskUserQuestion`で次を確認する。

- 「claudeが実装する（会話をドキュメントに保存せずにプランモードで進める）」
- 「自分で実装する（会話内容をドキュメントに保存して終了）」

### claude 実装

プランモードで実行する。
{壁打ちフェーズ}の結果をもとに実装計画を立て、実装する。

### ユーザー 実装: 壁打ち内容を保存して終了(claudeが実装する場合は不要)

壁打ち内容を `$HOME/.claude/discussion-history/` 配下に保存する（ディレクトリがなければ作成する）。

ファイル名: `$HOME/.claude/discussion-history/{YYYY-MM-DD}-{repository-name}-{テーマのスラッグ}.md`

フォーマット:

```markdown
---
date: { YYYY-MM-DD }
tags: [grill-me]
repository: { repository-name }
---

# {テーマ}

## 決定事項

{壁打ちフェーズで確定した内容を箇条書きで}

## 実装方針

{決定を踏まえた実装アプローチ}
```

保存後、保存先パスを一言報告する。

## 終了（ユーザーが実装する場合）

コードは一切書かない。保存したドキュメントのパスを再度案内してセッションを終了する。
